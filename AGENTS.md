# Developing TRAJYN

TRAJYN is an AI infrastructure research project. Prefer correct, reproducible experiments
and make routine engineering decisions autonomously. Keep implementations modular, typed,
documented, and tested.

- Make meaningful incremental commits and push development work regularly to GitHub.
  Use focused pull requests for substantial changes. Keep the public repository
  professionally organized and ready for external review.
- Run CI before merging verified changes into `main`. Keep the default branch functional
  and preserve published history.
- Report observed results, including failures. Never fabricate benchmarks, improvements,
  or research claims. Preserve experiment provenance, including model identifiers and
  versions when available.
- Keep credentials, private personal information, generated bulk data, and unrelated
  local files out of Git.
- Keep repository files, commits, and pull requests focused on the project. Omit unnecessary
  assistant attribution, generated-by notices, and co-author trailers. Make no false
  claims about authorship.
